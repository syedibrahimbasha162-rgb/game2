# Games in This Folder

## Proper Ludo (Browser)
Classic 4-player Ludo in the browser.

- You control Red.
- Blue, Yellow, and Green are CPU players.
- 4 tokens per player.
- 52-cell main track + home lanes.
- Roll 6 to leave yard.
- Safe cells, captures, exact finish, and three-6 penalty included.

Run:
```powershell
start C:\Game\index.html
```
